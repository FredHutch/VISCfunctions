# Example mAB dataset from DataSpace

A subset dataset from the Farzan CAVD 812 Study, looking at eCD4
neutralization.

## Usage

``` r
CAVD812_mAB
```

## Format

A data frame with 480 rows and 4 variables:

- product:

  Eight eCD4-Ig variants were tested

- virus:

  60 HIV pseudoviruses from 12 different clades

- ic50:

  ID50 titer

- ic80:

  ID80 titer
